# Chemistry Hangman Game

A Python-based Hangman game built with Pygame that combines chemistry learning with interactive gameplay.The game challenges players to guess chemical element names while featuring custom builtanimations,visual effects, and an interactive hint system.

## About The Project

This project was created to combine programming with chemistry education.Instead of simple traditional Hangman words, the game uses chemical elements from the periodic table as the guessing words.

The game includes a custom-designed interface, animated gameplay elements, and a hint system that adds an additional layer of interaction.

## Features

- Guess chemical element names from the periodic table
- Interactive letter selection system
- Animated Hangman character
- Hint box with a slot-machine mechanic
- Jackpot system that rewards players with hints
- Particle effects and animations
- Animated mouse trail effects
- Custom UI design and visual effects
- Randomized word selection
- Tracks previously used words during gameplay

## Technologies Used

- Python
- Pygame library 

## Installation and Running

To run the game, first make sure Python is installed on your computer.Download or you can clone this repository to your computer, then open a terminal inside the project folder. Install the required Pygame library by running `pip install pygame`. After the installation is complete, start the game by running `python game.py`.
